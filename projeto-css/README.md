# We Form - Registo de Entidades

O **We Form** é uma plataforma simples e intuitiva desenvolvida para facilitar o registo de entidades e parceiros. O projeto foca-se numa experiência de utilizador limpa, utilizando tecnologias web fundamentais para criar uma interface responsiva e funcional.

## 🚀 Tecnologias Utilizadas

- **HTML5:** Estruturação semântica das páginas de entrada e de formulário.
- **CSS3:** Estilização avançada com o uso de:
    - **CSS Grid:** Para o layout principal e alinhamento de áreas.
    - **Flexbox:** Para posicionamento interno de componentes e ícones.
    - **Variáveis CSS:** Para gestão de cores e bordas.
- **Font Awesome:** Utilização de ícones vetoriais para melhorar a navegação e feedback visual.
- **Google Fonts:** Integração da fonte "Roboto" para uma tipografia moderna.

## 📦 Funcionalidades

- **Página Inicial:** Apresentação do projeto com opções claras de navegação.
- **Formulário de Registo:** Sistema de cadastro de nova entidade com seleção de campo de atuação.
- **Gestão de Pontos de Coleta:** Campo específico para adicionar locais de atuação.
- **Navegação Fluida:** Links de retorno e ícones interativos.

## 📂 Estrutura do Projeto

```text
/we-form
│
├── /assets          # Imagens e ilustrações (Ex: hero.svg)
├── index.html       # Página principal/Landing page
├── cadastro.html    # Formulário de nova entidade
└── style.css        # Estilização global e layouts
```

## 🛠️ Detalhes Técnicos

O projeto utiliza o conceito de `grid-template-areas` no CSS para garantir que a ilustração e o formulário permaneçam centralizados e organizados na tela, independentemente do conteúdo, proporcionando um design equilibrado.
