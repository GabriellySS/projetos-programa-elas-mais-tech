# MyShop - E-commerce com React, Redux & TypeScript

O **MyShop** é uma aplicação completa de e-commerce que simula a experiência de compra, desde a listagem de produtos até a gestão de um carrinho dinâmico e autenticação de utilizador.

## 🚀 Tecnologias e Conceitos Aplicados

- **React & TypeScript:** Arquitetura baseada em componentes com forte tipagem de dados.
- **Redux Toolkit:** Centralização do estado global com Slices e integração via `<Provider />`.
- **Styled Components & CSS Variables:** Estilização híbrida com suporte nativo a **Dark Mode** via `index.css`.
- **Hooks & Context:** Uso de `useDispatch` e `useSelector` para interação com a Store.
- **Vite:** Build tool de última geração para performance.

## 🛠️ Funcionalidades

- **Gerenciamento de Estado:** Fluxo completo de adição e remoção de produtos no carrinho.
- **Login Simulado:** Alteração de interface baseada no estado do utilizador.
- **Interface Responsiva:** Design adaptável com variáveis de CSS dinâmicas.
- **Logs de Desenvolvimento:** Integração com Redux Logger para debug de ações.

## 📂 Como rodar o projeto

1. Instale as dependências: `npm install`
2. Inicie o servidor: `npm run dev`
