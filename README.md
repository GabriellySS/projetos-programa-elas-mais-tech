# 🚀 Projetos de Desenvolvimento - Elas + Tech

Este repositório é dedicado à minha jornada no **Elas + Tech**, um programa de aceleração de carreira para mulheres, realizado pela **Ada Tech** em parceria
com grandes empresas. Através de uma trilha intensa de aprendizado em **Front-end com React**, o programa foca em reduzir a lacuna de gênero no
mercado de tecnologia, capacitando mulheres para atuar em grandes ecossistemas digitais.

## 📂 Projetos

| Projeto             | Tecnologias Principais                              | Descrição                                                                               |
| :------------------ | :-------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **Ciclo de Vida**   | React (Class Components)<br>Material UI             | Estudo prático sobre os métodos de ciclo de vida (montagem, atualização e desmontagem). |
| **Current Weather** | HTML5, CSS3, JavaScript (API)                       | Aplicação para consulta de previsão do tempo em tempo real utilizando API externa.      |
| **MyShop**          | React, Redux Toolkit, TypeScript, Styled Components | E-commerce completo com gestão de estado global, carrinho e modo escuro.                |
| **Projeto CSS**     | HTML5, CSS3 (Flexbox/Grid)                          | Projeto focado em técnicas avançadas de estilização, responsividade e layout moderno.   |
| **Todo List JS**    | HTML5, CSS3, JavaScript                             | Versão funcional de lista de tarefas focada em manipulação do DOM e lógica com JS puro. |
| **My Todo List**    | React, Context API, TypeScript, SASS Modules        | App de tarefas com persistência no LocalStorage e estatísticas dinâmicas.               |

## 🛠️ Tecnologias & Ferramentas Exploradas

### Front-end Core

- **React (v19)**: Hooks, Context API, Componentes de Classe (Ciclo de Vida).
- **TypeScript:** Interfaces, Types e tipagem de eventos/props.
- **Lógica:** JavaScript ES6+ (Map, Filter, Reduce, Async/Await).

### Estilização & Layout

- **Modern CSS:** SASS, Styled Components, Material UI.
- **Design Systems:** Implementação de variáveis globais e tokens de design.

### Estado & Infraestrutura

- **State Management:** Redux Toolkit, Context API.
- **Versionamento:** Git (Gitflow e Conventional Commits).

## 📂 Como Navegar

Cada pasta neste repositório contém seu próprio arquivo de configuração e dependências.

1. Navegue até a pasta do projeto desejado: `cd nome-do-projeto`
2. Instale as dependências: `npm install` ou `yarn`
3. Execute localmente: `npm run dev` ou `npm start`
